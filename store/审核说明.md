# AI Video Tutor — 商店后台提交材料

本文件供 Chrome 应用商店 / Edge 加载项后台使用，各小节可按段落直接粘贴。
权限理由与 `wxt.config.ts`、以及构建产物 `.output/chrome-mv3/manifest.json` 的实际内容一致。

---

## 一、权限用途逐项说明

对应商店后台的「权限理由 / Permission justification」输入框。

| 权限 | 用途 |
|---|---|
| `storage` | 在用户设备本地保存扩展设置与用户自己填写的 API Key。API Key 只写入 `chrome.storage.local`，仅后台 Service Worker 读取。 |
| `activeTab` | 用户点击扩展图标打开侧边栏后，操作该标签页：投递消息给 content script 以读取当前播放进度与字幕，并在用户就画面提问时截取当前画面。 |
| `sidePanel` | 扩展的主要界面（对话、时间轴、设置）以浏览器侧边栏形式固定在视频旁边，不遮挡页面内容。 |
| `host_permissions: <all_urls>` | 两项必需能力：① 检测 `<video>` 元素、读取页面字幕的 content script 在 manifest 中声明式注入，而用户观看视频的网站无法预先枚举；② 扩展需要访问用户自己配置的 AI 端点，该地址由用户填写，同样无法预先枚举。扩展不在页面写入任何 DOM，不注入脚本，不修改页面内容。 |

### 关于本扩展**没有**申请的权限

上一版曾因「请求但不使用以下权限：scripting」被拒，相关权限已全部移除，请勿据旧版本判断：

- `scripting` — 已移除。content script 由 manifest 的 `content_scripts` 字段声明式注入，扩展从未调用 `chrome.scripting.*`。
- `tabs` — 已移除。扩展只用 `<all_urls>` host 权限与 `activeTab` 即可完成全部标签页操作，且从不读取 `url` / `title` / `favIconUrl` 等敏感字段。移除后也不再向用户展示「读取您的浏览记录」警告。

## 二、审核员测试指引

对应商店后台的「审核备注 / Notes for reviewer」。

本扩展采用 **BYOK（用户自带 API Key）**，没有自己的服务器。作者无法提供测试用 Key（那等同于代付第三方模型的费用），因此请按以下方式验证：

**无需任何 Key 即可验证的部分**（安装后点击扩展图标，侧边栏打开，标题下方会显示 `DEMO / MOCK` 徽标，表示当前处于演示模式）：

1. **页面视频识别** — 打开任意含 HTML5 视频的网页，侧边栏顶部会显示站点、视频标题与播放进度，并出现「已连接视频」标记。
2. **字幕读取** — 在带字幕（textTrack）或带 `.vtt`/`.srt` 的页面上，会出现「已读取字幕」标记，可基于字幕提问。
3. **本地视频** — 在侧边栏拖入一个 MP4/WebM 文件即可播放，并可另加载 `.srt`/`.vtt` 字幕文件。
4. **时间轴索引** — 对已加载字幕的视频建立索引后，时间轴页可列出带时间戳的知识片段。
5. **界面与设置** — 模型增删、角色分配、解释深度、背景设置等均可完整操作。

**验证真实 AI 回答**：在「设置 → + 添加模型」中填入您自己的任意 OpenAI 兼容端点的 Base URL、Model ID 与 API Key，点击「保存并检测」；检测通过后即可提问，扩展会把问题、视频标题、命中的字幕，以及在涉及画面时的一帧画面发送给该端点。

**演示模式说明**：无 Key 时模型回复由本地预置文案生成，全程带有 `[DEMO/MOCK]` 标记且界面顶部有醒目徽标，不存在把演示内容伪装成真实 AI 输出的情况。

请按后台表单的实际措辞核对后再提交。判断依据是代码的实际行为，对应关系如下。

| 表单问题 | 建议回答 | 依据 |

| 是否收集**个人通信 / 用户内容** | 是，且「仅用于扩展的核心功能」 | 用户主动提问时，问题、视频标题／平台／时长、命中字幕、联网搜索结果，以及（涉及画面时的）一帧画面会发送给用户配置的服务商。视频 URL 不发送。 |

| 是否使用远程代码 | 否 | 全部代码随扩展打包；不存在 `eval`、远程脚本加载或动态注入。 |
